# TCDOG

TCDOG is a lightweight Node.js and Express web application featuring a dog registry service and a responsive frontend client.

## Features

- **Express REST API**: Manage dog records with `GET`, `POST`, and `DELETE` endpoints.
- **Frontend Client**: Interactive HTML/JS interface to view, add, and delete dogs.

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) installed on your system.

### Installation & Running

1. Install dependencies:

   ```bash
   npm install
   ```

2. Start the server:

   ```bash
   npm start
   ```

3. Open your browser and navigate to:
   ```text
   http://localhost:3000
   ```
